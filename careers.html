How Risk Score Is Calculated

  • +1 if routine_cognitive_tasks >= 0.40
  • +1 if nonroutine_cognitive_tasks <= 0.20
  • +1 if social_tasks <= 0.10
  • +1 if job_zone <= 2
risk_label = High (score >= 3), Moderate (score >= 2), Low (score < 2)
# Rule-based risk scoring score = 0 if routine_cognitive_tasks >= 0.40: score += 1 if nonroutine_cognitive_tasks <= 0.20: score += 1 if social_tasks <= 0.10: score += 1 if job_zone <= 2: score += 1

Interpretation Key

Risk Score (0-4): higher means higher automation/displacement exposure.

  • Low: score < 2
  • Moderate: score = 2
  • High: score >= 3

Job Zone (1-5): preparation level required for entry.

  • 1: little/no preparation
  • 2: some preparation
  • 3: medium preparation
  • 4: considerable preparation
  • 5: extensive preparation

Task feature decimals (0-1): share of task statements matching that category.

How Match Score Is Calculated

safety_score = 1 - minmax(risk_score), access_score = 1 - minmax(job_zone) Very Disadvantaged / Disadvantaged: match = 0.45*safety + 0.55*access Moderate / Higher Opportunity: match = 0.60*safety + 0.40*access
# Group-specific matching engine safety_score = 1 - minmax(risk_score) access_score = 1 - minmax(job_zone) if youth_group in ["Very Disadvantaged", "Disadvantaged"]: match_score = 0.45*safety_score + 0.55*access_score else: match_score = 0.60*safety_score + 0.40*access_score

Career Metric Definitions

Risk Score (`risk_score`)

Meaning: Rule-based automation/displacement score.

Scale: 0 to 4.

Interpretation: Higher score means higher potential automation vulnerability.

Risk Label (`risk_label`)

Meaning: Categorical version of risk score.

Values: Low, Moderate, High.

Interpretation: Quick-read classification for decision support.

Job Zone (`job_zone`)

Meaning: O*NET preparation level for an occupation.

Scale: 1 to 5 (higher = more preparation).

Interpretation: Lower values are generally more immediately accessible.

Task Features

Fields: `routine_cognitive_tasks`, `manual_tasks`, `social_tasks`, `nonroutine_cognitive_tasks`.

Scale: 0 to 1 proportions.

Interpretation: Task composition inputs that drive risk-rule triggers.

Match Score (`match_score`)

Meaning: Group-weighted fit score for recommendations.

Scale: Relative ranking score.

Interpretation: Higher score means stronger balance of safety and access for that group.
