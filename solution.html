How the Model Works

How Calculations Work

  • KNN Imputation: fills missing mobility-related values using nearest neighbors in feature space. imputed_value = mean(value of k=5 nearest rows)
  • Youth Grouping: standardizes features then applies KMeans with 4 clusters. X_scaled = StandardScaler([pov20, mob_up, inc20, opp_gap]); youth_cluster = KMeans(k=4)
  • Label Mapping: clusters are ordered by average mobility and mapped to opportunity names. lowest mob_up → Very Disadvantaged ... highest mob_up → Higher Opportunity
